

# 🔐 Login & Registration System

## 📌 Project Overview
This project is a frontend-based Login and Registration System developed as part of the **OutriX Web Development Internship Program**.

It demonstrates form handling, authentication logic, validation, and UI/UX design using pure frontend technologies.

---

## 🎯 Objectives
- Implement login and signup functionality
- Validate user inputs
- Simulate authentication using LocalStorage
- Provide secure and user-friendly UI
- Redirect users to dashboard after login

---

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

---

## ✨ Features
- Login & Signup toggle
- Form validation
- Show / Hide password
- LocalStorage-based authentication
- Error handling
- Dashboard redirection
- Responsive UI
